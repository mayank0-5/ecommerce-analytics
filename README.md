# 🛒 E-commerce Orders Analytics

An end-to-end data analytics project analyzing e-commerce orders using Python, SQL and Power BI.

## 🎯 Problem Statement
Analyze e-commerce orders to find best selling products, top cities, revenue trends and customer behavior patterns.

## 🛠️ Tech Stack
- **Python + Pandas** — data cleaning and preparation
- **SQLite + SQL** — database and querying
- **Power BI** — interactive dashboard

## 📁 Project Structure

## 📌 Dataset
[Kaggle - E-commerce Data](https://www.kaggle.com/datasets/benroshan/ecommerce-data)

3 tables:
- List of Orders
- Order Details
- Sales Target

## 🚀 How to Run
```bash
pip install -r requirements.txt
python app.py
```
